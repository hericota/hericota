## 🛍️ Projeto em destaque — Strype

<div align="center">

### STRYPE

**E-commerce desenvolvido com Angular 22**

[![Acessar Projeto](https://img.shields.io/badge/🌐_ACESSAR_PROJETO-Online-success?style=for-the-badge)](https://strype-frontend.henriquegdall.workers.dev/)
[![Repositório](https://img.shields.io/badge/📁_REPOSITÓRIO-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/hericota/Strype)

</div>

No **Strype**, trabalhei principalmente no **Front-End com Angular**, desenvolvendo páginas, componentes, responsividade, pesquisa e filtros, gerenciamento de produtos e integração com uma API REST.

> **Importante:** a API utilizada pelo projeto foi desenvolvida separadamente por outro desenvolvedor. Meu trabalho não envolveu o desenvolvimento da API em Java/Spring Boot.

Também participei da etapa de publicação do projeto, configurando a integração necessária para que o frontend pudesse consumir a API em produção.

### ☁️ Estrutura utilizada no deploy

```text
Angular 22
    ↓
Cloudflare Workers
    ↓
API existente hospedada no Render
    ↓
MySQL hospedado no Aiven
```

Durante esse processo tive contato prático com **variáveis de ambiente, CORS, configuração da URL da API, build de produção e deploy**.
